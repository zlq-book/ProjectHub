## AI 项目解析与配置 API

2026-10-15 新增 **ProjectHub AI Assistant**：右上角点击“AI 助手”，右侧在“项目详情／AI 助手”之间切换，不增加第四栏。无选中项目时也可打开，切换或收起会保留本次运行中的会话和输入。

首版支持三个场景：

- **自然语言检索**：例如“帮我找到空气质量预警项目”。从真实项目库返回候选、分类、技术栈和匹配依据，可查看详情或将结果显示在项目列表。
- **生成简介**：例如“给 env-agent-backend 生成简介”。先选择项目并确认读取范围，再生成可编辑的建议；点击“保存简介”只更新简介。
- **辅助分类**：例如“把所有 Spring AI Alibaba 项目归类到 AI 项目”。先预览每个项目的原分类、建议分类和证据，可逐项勾选、改分类，确认后整批保存。

第一次使用前显示当前模型服务与项目元数据发送范围，点击“开始使用 AI 助手”后才可发送。默认范围为全部项目，也可选择当前筛选结果或当前项目。初次仅发送已保存的名称、简介、分类、技术栈、标签与必要时间，不默认读取全库 README；补充资料必须通过单独按钮选择并确认，根目录白名单文件的读取限制沿用下文。会话保存在内存，重启清空，不存储密钥。

每轮最多处理 100 个项目；超出时请先筛选或分批。每批最多 50 个元数据项目，每次模型请求完整 JSON 最多 64 KiB；读取补充资料每轮最多 3 个项目，生成简介每次只处理一个。截断、目录不可用和资料不足均明确提示。已有证据的分类建议可以先保存，待确认候选默认不勾选。

建议有效期 10 分钟。保存前核对项目快照，项目被编辑／删除时整批不保存；重复确认不重复覆盖。取消请求后忽略晚到结果，导入项目库或保存 API 配置会使旧建议失效。保存期间不能新开完整项目编辑表单，避免旧表单覆盖新资料。

“最近打开”与“最近修改资料”使用不同时间字段；V1.4 的“最近开发／一个月没有代码更新”读取真实 Git 证据，每轮最多 20 个项目；不会把资料更新时间当作代码更新时间。助手的 Git 结果可进入开发进度查看，摘要需单独确认发送。IDE／终端启动、模块问答和跨项目对比暂未接入对话工具；原有详情中的手动打开功能继续可用。

浏览器仅展示助手界面，不调用真实模型或读取项目文件。AI 助手的实现与验证情况见 [验收记录](./2026-10-15-AI助手验收记录.md)，方案见 [设计稿](./superpowers/specs/2026-10-15-projecthub-ai-assistant-design.md)。

此前 AI 助手阶段验证为前端 70 项、Rust 54 项通过；V1.4 的最新结果以本页上方验收记录为准。使用源码运行 `npm.cmd run desktop` 可启动当前版本。

左侧底部点击“配置 API”，填写兼容 Chat Completions 的 API 基础地址、模型名称和可选 API Key。基础地址可填服务方的 `/v1` 地址或完整 `/chat/completions` 地址；接口请求采用模型服务的标准消息结构，参考 [Chat Completions 接口文档](https://api-docs.deepseek.com/api/create-chat-completion/)。远程服务使用 HTTPS，本机模型可用 `http://127.0.0.1:端口/v1`。模型名称按实际服务填写，不自动固定供应商或模型。

“获取模型列表”使用当前窗口尚未保存的地址与密钥请求 `/models`，结果作为模型名称的下拉建议，仍可手动填写。地址、密钥变化后旧候选清空；服务未提供模型列表时可直接手填。“测试连接”使用当前模型发起最多 16 个输出 token 的简短对话请求，显示成功与耗时或具体错误，可能产生少量费用。两项操作都不自动保存配置，也不发送项目资料；密钥留空且未勾选清除时由后端复用原密钥，不向界面回传。

添加或编辑项目时填写本地路径，点击“AI 解析”。解析前会显示使用的接口和发送范围：根目录 README、依赖清单、最多一层目录名称；不读取源码正文或 `.env` 等独立密钥文件。项目根目录绝对路径不作为单独字段附带，README 与依赖清单中已有的文本按内容发送。AI 解析是用户主动调用配置接口的联网功能，原有“识别项目”仍只使用本地规则。

结果先展示项目名称、简介、分类、技术栈、标签五项预览；“应用解析结果”会覆盖这五项，路径、备注、收藏及默认工具保留。应用后可继续编辑，最后点击“保存项目”或“保存修改”。解析失败、放弃结果均不改变当前资料。

API Key 在 Windows 下用当前用户 DPAPI 加密，单独保存在应用数据目录 `ai-settings.json`；界面只显示是否已配置，不回显原密钥，不写浏览器存储或 SQLite 备份。密钥留空保留原值，勾选“清除已保存的 API Key”可删除。基础地址和模型同时留空可停用。保存配置不会发起模型请求。

浏览器可预览配置与解析入口，保存配置和读取本地项目解析需要桌面版。已完成本地模拟接口与表单测试不等于所有模型供应商均已实测；真实模型需配置自己的地址、模型和密钥。2026-10-14 已重新生成包含极简界面、新图标、API 配置和 AI 解析的 Windows x64 安装包：`src-tauri/target/release/bundle/nsis/ProjectHub_0.3.0_x64-setup.exe`。此次保留 0.3.0 版本号，安装前先退出正在运行的 ProjectHub。

## 标签整理使用方法

左侧点击“标签管理”，可以搜索自定义标签、查看关联项目数量，或切到“技术栈”进行独立筛选。自定义标签右侧提供重命名和移除操作；确认框列出全部受影响项目，操作不受当前项目列表的筛选影响，每次最多 500 个关联项目。

重命名到已有标签时会合并去重，保持首次出现顺序；名称区分大小写，去首尾 Unicode 空白及 BOM，支持 1–80 个字符。移除仅删除关联记录里的自定义标签，不移除项目、技术栈或源文件。技术栈请在项目资料中编辑。

标签或混合来源的当前筛选随标签重命名/移除同步，明确的技术栈筛选保持原值。项目资料表单中未修改的标签与技术栈文本保留原数组，避免仅编辑名称时拆分含逗号的标签；主动修改文本仍按中英文逗号分隔。

## v0.2 使用方法

“发现项目”入口位于左侧导航。每行填写一个根目录或使用选择器追加目录，设置扫描深度后开始扫描。候选默认全部不选，已录入的路径禁用勾选；确认名字、路径、技术栈和统一分类后点击导入。扫描不写库，导入时会再次验证目录，重复或不可访问路径会跳过并显示结果说明。

项目列表上方点击“批量管理”，勾选项目或全选当前结果，然后使用底部操作栏。选择跨搜索/分类筛选保留；调整分类与移除确认框会列出全部操作对象。移除仅删除索引。每批最多操作 500 个项目。

扫描跳过依赖、构建目录、符号链接和 Windows 联接点；最多访问 5000 个目录、20000 个目录项、返回 500 个候选。采用 15 秒协作式遍历预算，检查点超过预算就停止后续工作并标记结果不完整；单次同步文件 I/O 无法被抢占，慢磁盘或网络目录可能让执行及取消等待更久。普通目录没有特征文件时请手动添加。

浏览器可以体验批量管理，但不能读取本地目录。扫描候选、取消和导入的组件测试使用模拟的本地接口，不等同于真实文件系统扫描。详见 [v0.2 迭代与验收记录](./v0.2迭代记录.md)。

## 启动 Windows 桌面版

需要 Node.js 22.12+（本次使用 24.19）、当前稳定 Rust 工具链、Microsoft C++ Build Tools（桌面 C++ 工作负载、MSVC 与 Windows SDK）和 WebView2。

- [Tauri Windows 开发前置条件](https://v2.tauri.app/start/prerequisites/)
- [Rust 官方安装入口](https://rustup.rs/)

补齐工具后运行：

```powershell
npm.cmd install
npm.cmd run desktop
```

桌面版初始为空项目库。添加真实项目目录后，可在设置里填写 IDE 的完整 `.exe` 或 `.com` 路径。例如 IDEA 可填写 `idea64.exe` 的绝对路径；留空会尝试系统 PATH。VS Code／Cursor 还会检查常用安装目录。自定义程序仅接受一个可执行文件路径，不接受 Shell 字符串或脚本。

全局工具选择“文件资源管理器”表示用 Explorer 打开；单个项目的“跟随全局设置”会使用该偏好。

## 数据与备份

默认数据库位于 Tauri 应用数据目录，Windows 通常是 `%APPDATA%\com.projecthub.desktop\projecthub.sqlite`，实际完整位置可在设置中查看。无需 Spring Boot、MySQL 或云服务。

导入前会提示替换项目库与设置。软件先读取并验证备份的同一个只读快照，再对现库加写锁、自动备份、重新建立受约束的表结构、插入验证后的行并提交事务。失败会保留原库。自动备份保存在数据库同目录，名为 `projecthub-before-import-时间-UUID.sqlite`。

文件识别只查看根目录的已知配置文件，每个文件最多读取 128 KiB，过大的文件跳过；不递归，不跟随特征文件符号链接，不执行 README 或 package.json 命令。README 作为纯文本显示，不渲染任意 HTML。
