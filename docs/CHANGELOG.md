# 版本迭代记录

按时间顺序记录 ProjectHub 每一次迭代：每个版本做了什么、新增了什么、优化了什么、修了什么，以及**当轮到底验证到什么程度**。

**记录口径**（不改写历史结论）：

- 测试项数、构建结果、安装包字节数照抄当轮记录，不补算、不合并，也不把后来的结果回填到早期轮次。
- 「已实测」与「未实测」分开列。打包成功不等于安装验收通过，浏览器检查不等于桌面验收，前端模拟接口不等于真实文件系统。
- 版本号照原文档写。历史上并非每轮都发新版本号：`v1.0` 是设计方向而非发布号；`0.3.0` 之后直接到 `1.4.0`，中间没有 `1.0.0`–`1.3.x` 的发布。
- 每节末尾给出当轮记录文件，细节和原始证据都在那里。

## v0.1 · MVP 最短链路（2026-10-13）

文档只写「ProjectHub MVP（v0.1）」，版本配置里**没有出现过 `0.1.0`**。

**新增**

- Tauri 2 + React + TypeScript + Vite 工程；Rust 负责路径校验、项目识别、SQLite 与进程启动。
- 三栏浅色 Fluent 界面，深色主题、卡片／列表切换、分类、收藏、最近打开、标签筛选。
- 添加、编辑、重新定位、移除索引；扫描只读根目录有限字节，绝不执行项目脚本。
- SQLite 保存项目与设置；备份导出／导入，导入前验证结构并自动备份现有库。
- 独立的浏览器示例预览（独立 localStorage，不能访问本地文件系统），桌面初始项目库为空。
- 图标 ICO 与 32／128／256 px PNG。
- 明确不做：P1 批量扫描、Git、P2 AI；原型中的磁盘占用／目录大小不展示虚构数值。

**修复**

- 独立源码审查发现并修复：自路径识别、并发导入、外来 schema、异步导入刷新、忙碌状态关闭弹窗；复审通过。

**验证**

- 已实测：`npm.cmd test` **4/4**（五类字段搜索、规范路径重复、收藏与最近打开、更新冲突与移除索引）；`npm.cmd run build` 通过（TypeScript 严格检查 + Vite 8 生产构建）；`npm.cmd audit` **0 已知漏洞**；浏览器实测新增后列表 **8 → 9**、`d:/projects/PROJECTHUB-ui-test/` 判重未产生第十条、检索 `SQL` 命中简介／技术栈／名称、移除确认「不删除本地文件」后恢复 **8 条**、窄屏 **600×850** 单列卡片且详情区数量为 0。
- 未实测：**Rust 测试未执行**（源码 12 个测试，当时无 Cargo／Rust／MSVC，「不计为通过」）；**Tauri 桌面启动未执行**；**NSIS 安装包未生成**（`package:windows` 停在 Cargo metadata）。

## 体验优化第一轮（2026-10-13）

本轮**未设版本号**，文档只写「沿用既有原型和 MVP 范围」。从测试数量（4/4 → 8/8）看处在 v0.1 与 v0.2 之间，但原文档没有把这一轮归入某个版本。

**优化**

- 提高卡片简介、标签、路径、详情文字字号与次要文字对比度。
- 窗口高度不足 **850 px** 时默认收起分类，保证标签、设置、底部添加入口可见。
- 搜索按空格拆多词，分别匹配名称、简介、路径、标签或技术栈，**所有词都匹配**才返回。
- 显示关键词／分类／状态／标签筛选条件，支持单项移除与清除全部。
- 筛选后详情只展示结果集中项目；切换项目重建详情面板，避免沿用上一项目滚动位置。
- 浏览器示例仓库先持久化成功再替换内存，存储失败不留假新增／假修改／假删除。
- 最近打开与更新按时间戳排序，正确处理不同 UTC 偏移。
- 预览录入增加名称、分类、工具、简介、备注、标签上限校验。
- 统一中文错误消息；选择目录、识别、保存期间锁定表单；移除期间禁止关闭确认框。
- 初始化／重试／导入后统一读取项目与设置；未完整加载时阻止保存默认设置。
- 原生文件选择器不持有数据库任务锁，选择结束后的备份／导入仍参加串行保护。

**修复**

- 新增 **4 项回归测试先失败**，修复后 **8/8** 通过；复审发现并修复「重试遗漏设置」。

**验证**

- 已实测：TypeScript 严格检查与生产构建通过；**1280×720** 浏览器实测 `env-agent SPRING` 返回 **1 条**、清除筛选恢复列表、前端分类返回 **2 条**、旧后端详情 **0**；添加弹窗「浏览」显示中文限制提示且无 `Error:` 前缀。截图清晰度异常，当轮结论以控件状态与交互结果为准。
- 未实测：Rust 侧选择器拆分仅经源码复审，**未执行 Cargo 编译或桌面实测**。

## v0.2 · 项目整理版（2026-10-13）

发布号 `0.2.0`（npm、Cargo、Tauri 一致），UI 标记 `v0.2`。数据库结构不变、`user_version=1` 兼容，仍不含 Git 与 AI。

**新增**

- 多根目录发现：接受 **1–20 个根目录**、**1–4 层**深度；跳过 `.git`、`node_modules`、`target`、`dist`、虚拟环境，以及符号链接与 Windows 联接点。
- 异步扫描与独立取消命令。
- 扫描限额：每次最多访问 **5000 个目录 / 20000 个目录项**、返回 **500 个候选**，**15 秒**协作式时间预算；超限即停止并提示结果不完整。
- 候选展示名称、路径、技术栈，**默认全不选**；可搜索、勾选、全选当前结果，导入时统一分类。
- 导入仅在确认后以事务写入：重复路径跳过并报告、新路径保存时再校验、不存在路径不导入、不可恢复错误回滚整个事务。
- 批量管理：全选当前结果、收藏／取消收藏、统一分类、确认后移除索引；选中跨筛选保留，确认框显示数量与具体名字。

**优化**

- 列表中删除与修改合并为单个事务。
- 拆出 `DiscoveryDialog`、`BatchToolbar`，App 保持为状态协调层。
- 浏览器批量整理可真实交互，扫描与文件选择保留明确的桌面版限制。

**修复**

- 复现并修复「可选字段 `undefined` 覆盖原值」。

**验证**

- 已实测：`npm.cmd test` **20/20**（15 项仓库测试 + 5 项扫描组件测试，新增接口测试先失败再通过）；构建通过；`npm.cmd audit` **0 已知漏洞**；浏览器批量收藏两个示例、批量改 AI 分类、跨筛选显示「含 **2 个筛选外项目**」、取消移除后仍有 **10 条**、执行移除恢复 **8 条**、扫描入口提示需桌面版且不伪造结果；源码复审修复条件关闭弹窗、取消后迟到结果、超时预算检查、目录变化使候选失效、扫描状态释放。
- 未实测：**Rust 未编译未执行**（源码 **19 项**测试）；**桌面真实扫描与事务未执行**（原文档：「前端模拟接口测试和源码审查不能替代桌面验收」）；**安装包未生成**。

## v0.3 · 标签整理版（2026-10-13）

发布号 `0.3.0`（npm、lock 根包、Cargo、Tauri 五处一致），UI 标记 `v0.3`。保留三栏界面与既有 schema，不新增依赖。

**新增**

- 自定义标签与技术栈**分开**展示、搜索、统计（数量按项目去重）；技术栈只提供筛选，编辑仍在项目资料表单。
- 标签重命名与移除；重命名到已有标签时**合并**，保持首次出现顺序并去重，只改 `tags` 不改 `techStack`。
- 确认框列出全部受影响项目的名称与路径，**每次最多 500 条**，超出提示分批使用项目资料编辑。
- 服务接收明确 ID 清单 + 源标签 + 可空目标标签；ID 缺失、源标签消失或输入非法时**整批失败**，不部分更新；移除标签不移除项目。
- 桌面走 SQLite 单事务、浏览器一次持久化后替换内存；失败保留清单便于重试。
- 自定义／混合来源筛选随重命名与移除同步，明确的技术栈筛选保持原值。
- 新增 `changeTag(ids, source, target)` 服务、Tauri 命令与独立 `TagManagerDialog`（统计、搜索、技术栈切换、错误重试、忙时不可关闭）。
- 标签名规则：区分大小写；去首尾 Unicode White_Space 与 BOM；非空且**最多 80 个 Unicode 码点**（JS 用 `\s`+U+0085，Rust 用 `is_whitespace`+U+FEFF）。

**优化**

- 未修改标签／技术栈文本时保留原数组，避免仅编辑名称就拆分含逗号的标签；主动修改仍按中英文逗号解析。
- 仅更新 `tags` 与 `updatedAt`。

**修复**

- 审查发现的**逗号、旧筛选、NEL/BOM** 三个问题分别复现后修复；`build` 时编译检查捕获并修正新增测试里「不支持的定位参数」。

**验证**

- 已实测：`npm.cmd test` **37/37、5 个测试文件**（仓库 **22** 项、标签管理组件 **5** 项、项目表单回归 **2** 项、主界面回归 **3** 项、扫描组件回归 **5** 项）；测试先行时先出现 **6 项失败**，组件可加载后出现 **5 项交互失败**；构建通过；Python 校验版本**五处均为 0.3.0**；浏览器验收（样例 `v0.3 标签验收`，路径文本 `D:\ProjectHubChecks\TagIteration`，**浏览器不验证也不访问该路径**）验证了合并、取消后重移除、技术栈「旧标签」保留与精确筛选、清理后恢复 **8 个**示例。
- 未实测：Rust 源码 **22 项**测试（本轮新增 3 项）**未编译、未执行**；**桌面与安装包未实测、未生成**。源码复核通过，但原文档注明「不替代 Rust 编译」。

## AI 项目解析与 API 配置（2026-10-14）

挂在 `0.3.0` 上的第一项联网能力，没有单独的验收文档，事实来自 [Windows 打包记录](./Windows打包记录.md) 与该版 README。

**新增**

- 设置里「配置 API」：兼容 Chat Completions 的基础地址（`/v1` 或完整 `/chat/completions`）、模型名称、可选 API Key。
- 添加／编辑项目时「AI 解析」：先展示名称、简介、分类、技术栈、标签五项预览，「应用解析结果」只覆盖这五项，路径、备注、收藏与默认工具保留；解析失败或放弃结果不改变当前资料。

**验证**

- 已实测：本地模拟接口与表单测试通过；浏览器可预览配置与解析入口。
- 未实测：保存配置与读取本地项目解析只能在桌面版；**不等于所有模型供应商均已实测**，真实模型需自行配置地址、模型与密钥。

## v1.0 · 极简 Windows 开发工具界面（2026-10-14）

**不是一次版本发布**：发布号仍为 `0.3.0`，本轮是把界面按 **V1.0 设计方向**重做。

**新增与调整**

- 白灰中性界面 + 蓝色强调主要操作；技术栈统一浅灰；深色主题用对应中性灰。
- 项目库默认改为**列表**：按名称、简介、技术栈、路径、最近更新时间**五列**展示，**46 px** 行高，长文本省略并可悬停查看；窄窗口横向滚动，不隐藏列。
- 保留卡片视图与持久化偏好，**已保存的卡片偏好不被强制覆盖**。
- 侧栏只保留常用功能与分类，移除底部统计、进度条、重复添加按钮及装饰文案。
- 单击选择并展示详情；关闭详情保留选中并释放列表宽度；卡片鼠标单击即时高亮、**延迟 500 ms** 展开，双击取消延迟并使用默认工具；键盘选择即时展开。
- 详情展示 Git 仓库、当前分支、路径可用状态、路径、分类与时间；主操作直接打开 IDEA，终端与目录为次操作。
- Git 用选中项目 ID 查询实际路径，固定参数执行只读命令，无 Shell、不联网；**每个 Git 命令 3 秒预算**；远程 URL 凭据与查询参数不展示；异步返回不覆盖另一个项目。

**验证**
