# ProjectHub MVP 实施计划

依据根目录 `ProjectHub设计文档.md` 第一阶段和 `原型图.png`，直接实现既有设计。原始资料保留。

## 范围与约束

- Tauri 2 + React + TypeScript + Vite；Rust 管理路径、识别、SQLite 和进程启动。
- 三栏浅色 Fluent 风格；深色主题、卡片/列表、分类、收藏、最近打开、标签筛选。
- 添加、编辑、重新定位、移除索引；扫描仅读取根目录有限字节，绝不执行项目脚本。
- 使用真实系统时间；桌面初始项目库为空。浏览器提供明确标注的独立示例预览，不能访问本地文件系统。
- SQLite 保存数据和设置，支持数据库备份导入/导出；导入前验证结构并备份现有库。
- 不实现 P1 批量扫描、Git 与 P2 AI。原型中的磁盘占用/目录大小不展示虚构数值。

## 顺序与验证

1. 建立工程、类型与服务边界，先编写搜索/筛选/预览 CRUD 测试，再实现对应逻辑。
2. 实现三栏 UI、对话框、设置、可访问性与响应式样式。
3. Rust 服务分为路径/识别、数据库、启动、Tauri 命令；对重复路径、普通目录、读取限额、重启持久化、移除不删文件编写测试。
4. `npm test`、`npm run build`；环境具备 Rust/MSVC 时执行 `cargo test` 和 NSIS 打包。
5. 启动浏览器预览检查界面及关键交互，写明桌面实测与打包边界。

无 Git 仓库，不执行提交；开发在当前用户指定目录内进行。
