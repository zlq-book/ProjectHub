# v0.2 项目整理版

基于设计文档的第二阶段开发批量发现和管理，保持只维护索引、不写项目源文件的约束。

## 功能与边界

1. 多个根目录、1–4 层深度发现潜在项目；扫描读取目录与已有特征文件，跳过 `.git`、`node_modules`、`target`、`dist`、虚拟环境等，跳过符号链接与 Windows 联接点。
2. 异步扫描支持用户取消。每次扫描最多访问 5000 个目录/20000 个目录项、返回 500 个候选，使用 15 秒协作式时间预算；检查点超限时停止后续工作并提示结果不完整。同步文件 I/O 无法被中途抢占，慢磁盘/网络目录单次调用可能超出预算，取消也会等当前调用结束。扫描期间用户可退出对话框，发出取消请求，不落库。
3. 候选展示名字、路径、技术栈，默认全不选；用户可搜索、勾选、全选当前结果，为导入项目指定统一分类。
4. 导入仅在点击确认后进行，数据库事务写入；重复路径跳过并报告，新路径保存时再次校验，不存在路径不导入。不可恢复错误回滚整个写入事务。
5. 列表批量管理支持全选当前结果、收藏/取消收藏、统一分类、确认移除索引。选中项目跨筛选保留，操作前显示数量与具体名字。删除与修改使用单个事务。
6. 浏览器的批量整理可真实交互，扫描/文件选择保持明确的桌面版限制。浏览器预览数据、桌面 SQLite 不混用。
7. npm、Cargo、Tauri 版本同步到 0.2.0；不改变数据库结构，不包含 Git/AI。

## 实现与验收

- 先扩展 `src/services/projects.test.ts`，验证批量保存一次、失败回滚、失效 ID 拦截、重复路径跳过。
- `src/services/projects.ts` 封装新增扫描/取消/批量接口；前端组件分为 `DiscoveryDialog` 与 `BatchToolbar`，保持 App 为状态协调层。
- `src-tauri/src/services/discovery.rs` 实现限深扫描与取消令牌；`db` 扩展事务导入、批量更新与移除，`commands` 注册异步扫描命令和独立取消命令。
- `npm test`、`npm run build`；浏览器验证批量收藏、分类、移除确认、取消保持索引、普通筛选与选择联动。
- Rust 工具链依旧缺失时，不宣称扫描、SQLite 事务或安装包已通过；补充 Rust 测试源码与后续验收步骤。
