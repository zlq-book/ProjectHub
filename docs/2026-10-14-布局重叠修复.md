# 详情布局重叠修复

触发条件：窄窗口沿用旧样式中的固定定位详情浮层，覆盖项目区域；长技术栈标签保持不换行，可能撑出详情面板。顶部搜索区也未明确允许收缩。

修复：显式命名 Grid 区域；桌面宽度下详情始终占据独立列，清除旧 fixed/inset/width。800–1060 px 保持 190 px 导航、300 px 详情与剩余项目区。760 px 及以下详情改为占据内容区的独立页面，关闭详情恢复列表。顶部搜索可缩、操作按钮不缩；详情简介、标签和长路径约束在面板内换行。

验证使用生产构建页面和长简介、63 字符技术栈标签，不修改桌面真实项目库。
