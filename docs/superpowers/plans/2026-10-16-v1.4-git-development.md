# ProjectHub V1.4 实施计划

设计已获用户“设计实现”授权。以 `../specs/2026-10-16-v1.4-git-development-design.md` 为验收依据，连续执行全部阶段，不创建 Git 提交。

## 全局约束
- 保留原项目管理、标签、AI 助手和模型配置能力；当前源码目录无 Git 元数据。
- 只读系统 Git，不执行仓库写操作、不隐式联网；失败和截断明确展示。
- 活跃度为当前 HEAD 可达历史、全部作者、提交者时间；资料更新时间独立。
- 后端 camelCase 序列化，对应 TypeScript 独立协议；命令统一 `development_*`。
- 主代理负责 App、前端和命令注册；每次仅一个实施子代理负责指定后端文件，避免共享文件覆盖。
