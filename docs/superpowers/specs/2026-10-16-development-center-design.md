# 开发状态中心设计

用户已于 2026-10-16 确认聊天中展示的方案，本文件记录该方案。

- 汇总页：活跃项目、自然周提交数、有未提交更改项目数、最近七个自然日趋势、项目状态表。
- 当前分支、全部作者、提交者时间、本地自然日、周一起算；跨项目提交数按项目累计，同仓库重复录入也分别计数。
- 活跃项目定义为最近七个自然日有提交的项目；最近开发展示当前分支最近提交时间，不用资料更新时间替代。
- 数据读取失败显示未知；部分历史只能报告已读取下限，不伪造完整零值。非 Git 项目无提交活动，日志和任务仍可用。
- 点击项目默认进入概览；五个标签依次为概览、提交记录、文件变更、开发日志、任务。原活跃度并入概览。
- 保留提交定位、摘要转日志、Diff 收起右栏、返回中心、日志任务编辑能力。
- 复用现有接口，不修改数据库和 Git 查询命令；同时最多两个项目读取。刷新重新获取状态与活动。
- 自动化验证统计日期边界、部分失败、刷新与项目导航；执行前端全量测试和生产构建。桌面交互另行声明验证边界。
