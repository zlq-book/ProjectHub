# ProjectHub 界面视觉刷新设计

日期：2026-10-19。状态：已实施并通过前端测试、构建与无头浏览器截图检查。范围：侧边导航、顶部工具栏、项目列表、项目详情卡、整体蓝白配色与响应式。

## 1. 目标与边界

用户希望按参考截图的方向提升界面质感：统一图标与间距、强化核心操作、降低列表拥挤感、把项目详情做成独立卡片、统一蓝白配色与圆角阴影。

已确认采用范围 A：只保留真实功能入口，不新增截图中的通知铃铛、用户头像和侧栏推广卡；技术栈使用低饱和彩色标签；深色主题同步适配。

不改项目增删改查、Git 读取、AI 助手、周报、批量管理、备份导入等行为，不改数据库和命令协议。

新增 `src/styles/visual-refresh.css`，在 `experience.css` 之后加载，作为最终视觉覆盖层。

## 3. 侧边导航

- 宽度 236px，纯白背景、右侧 1px 边框，内边距 20/14。
- 品牌 22px，`v1.5` 标记改为可见浅蓝胶囊。
- 导航项高 44px、圆角 10px、图标 20px、文字 14px；选中态为浅蓝底、蓝色文字、左侧 3px 指示条。
- 数量改为右侧胶囊；设置与主导航分隔，配置 API 固定在底部。
- 不新增推广卡。

## 4. 顶部工具栏

- 高度 68px，白底、底部边框，左右 24px。
- 搜索框高 44px、圆角 12px、浅灰底；聚焦时白底 + 蓝色描边 + 浅蓝光圈。
- AI 助手为浅蓝底/蓝字按钮；添加项目为蓝色主按钮并带轻阴影；设置图标弱化。
- 保留所有 aria-label、键盘快捷键和现有点击行为。

## 5. 项目列表

- 表格放入白色圆角卡片容器，1px 边框 + 轻阴影；表头 46px，数据行 58px。
- 悬停浅灰蓝，选中行浅蓝底并在首列显示 3px 蓝条。
- 项目名 13.5px/600；简介 12.5px 弱化色；路径用等宽字体；时间 11.5px。
- 收藏星默认 45% 透明度，悬停或已收藏时高亮。
- 技术栈标签按已知技术映射低饱和色调，未知标签保持中性灰蓝。

## 6. 项目详情卡

- 详情栏改为独立浮层卡片：外边距 14/18、圆角 16px、白底、轻阴影、可滚动。
- 页签改为分段控件；标题 21px，文件夹图标 46px，收藏星在标题右侧。
- 简介 13px/1.75；技术栈彩色标签。
- 路径、类型、Git、分支、状态、时间、工具信息收进浅灰信息面板，行间细分隔线，路径保留复制按钮。
- “查看开发进度”为整行浅蓝按钮；项目简介、快捷操作、标签、备注按区块分隔。
- 快捷操作和移除入口保持现有功能，不新增假入口。

## 7. 响应式

- ≥1700px：侧栏 252px，详情 420px。
- ≤1380px：侧栏 212px，详情 332px，内容留白收紧，保证列表五列完整可见。
- ≤1060px：侧栏 200px，详情 310px。
- ≤760px：侧栏 64px 图标栏、隐藏文字和数量；顶栏压缩；详情保持可用；表格横向滚动，不产生页面横向溢出。

## 8. 验证

- 前端 20 个测试文件、108 项测试通过；`npm.cmd run build` 通过。
- 无头 Edge 检查 1535×1025、1280×900、760×900 三档浅色界面，以及 1535×1025 深色主题；截图位于 `.verification/ui-refresh/`（开发期产物，不作为用户数据）。
- 1535 宽下列表五列与标签完整显示；1280 宽下列表五列完整、标签允许换行；760 宽下侧栏折叠为图标栏，表格在卡片内横向滚动。
- 浏览器预览使用 8 个示例项目，真实项目数量与 Git 状态需在桌面版验收；本轮未重新打包安装包。

## 9. 不包含

- 通知中心、用户头像、侧栏推广卡等没有业务功能的装饰入口。
- 分类数量角标、列表 kebab 菜单等未在现有交互中定义的新功能。
- 新的页面路由、数据字段或业务流程。
