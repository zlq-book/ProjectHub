# ProjectHub 整体体验优化

用户已选择 A：整体优化项目库、开发状态中心、周报与设置。沿用简洁 Windows 工具样式，保持既有 Git、AI、数据库和周报业务口径。

## 设计

采用渐进增强：直接改善现有页面的信息层级及操作闭环。仅换皮无法修复无效操作；全面重建会破坏现有功能与习惯，因此不采用这两种方案。

- 首页增加简洁的继续工作入口，区别于“全部项目”，不堆统计卡片；项目列表及原有管理操作保留。
- 项目搜索只在项目区展示。开发中心和周报区使用页面标题与说明，移除无效的项目搜索／添加／助手入口。Ctrl+K 从功能区回到项目搜索；导航使用可访问名称、当前位置和跳至正文入口。
- 项目搜索、分类、状态和标签随项目视图记住，返回时恢复；明确操作“清空筛选”才清空。切换导航保留周报现有编辑状态。
- 周报基本信息与作者归入可折叠配置，有已保存配置时默认收起；项目、材料支持本地检索，选择数在筛选后仍可见，不暗中清空选择。项目全选只作用于搜索结果，仍遵守 20 个上限。
- 历史周报按日期、填报人检索；已打开周报可直接切版本，切换前保存脏稿，失败不切换。编辑页显示保存状态，支持 Ctrl+S；生成／采用／导出口径保持不变。
- 周报编辑区保留固定底部导出操作，桌面留出正文空间，窄屏自动换行；长解释及来源快照渐进展开。
- 开发中心统计保留原有真实数据及未知语义，视觉改为紧凑横条，减少大卡片干扰；项目筛选空状态提供重置。
- 设置中的 IDE 路径作为高级配置折叠，备份替换警告始终可见；无障碍焦点、主题对比、减少动画及紧凑控件统一检查。

## 验证

先验证导航和筛选恢复、周报检索不丢选择、Ctrl+S 与脏稿版本切换等交互，再运行完整前端测试与生产构建。以无头 Edge 检查 375／760／1060／1440 的浅色／深色布局。此次修改以 React 与样式为主；没有后端变化时不重复声称验证真实模型、原生 GUI 或生成新安装包。
