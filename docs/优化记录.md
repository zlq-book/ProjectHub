# 第一轮优化记录

2026-10-13，沿用既有原型和 MVP 范围。

## 已调整

- 提高卡片简介、标签、路径、详情文字的字号与次要文字对比度。
- 高度不足 850 px 的窗口默认收起分类，使标签、设置和底部添加入口可见。
- 搜索按空格拆分多个词，分别匹配名称、简介、路径、标签或技术栈，所有词都匹配时返回项目。
- 显示关键词、分类、状态和标签筛选条件，支持单项移除及清除全部。
- 筛选后的详情只展示仍在结果集中的项目；切换项目重建详情面板，避免沿用上一项目的滚动位置。
- 浏览器示例仓库先持久化成功，再替换内存数据；存储失败不会留下假新增、假修改或假删除。
- 最近打开与更新按时间戳排序，正确处理不同 UTC 偏移。
- 预览录入增加名称、分类、工具、简介、备注和标签上限校验。
- 统一中文错误消息；选择目录、识别和保存期间锁定表单，移除期间禁止关闭确认框。
- 初始化、重试和导入后的刷新统一读取项目与设置；未完整加载时阻止保存默认设置，避免覆盖已保存偏好。
- 原生文件选择器不持有数据库任务锁，选择结束后的备份/导入仍参加串行保护。
