# 模型列表与连接测试

用户要求：配置 API 中增加获取模型和测试按钮，参考模型输入框加获取列表按钮的截图。

实现：模型名称为可手填的原生下拉建议输入框；获取模型列表读取当前地址对应的 GET /models 接口，保留手填值。返回 ID 去空、去重、排序，最多保留 5000 个候选，响应最大 1 MiB。基础地址和完整 chat/completions 地址均支持推导。

测试连接：使用当前地址、模型和密钥，POST 简短对话，最多 16 个输出 token，不发送项目资料；接受文本或推理文本回复，空或错误结构不计成功。超时 30 秒，禁用跳转；显示耗时和授权、地址、额度等错误。界面提示可能产生少量费用。

获取和测试均不保存配置。空密钥且未勾选清除时，只在后端解密复用已有密钥；本次填写的新密钥无需落盘即可测试。所有操作期间禁止重复提交和修改参数；地址或密钥变化时清空旧候选和提示。浏览器不执行真实请求。

验证：先执行新增前端测试确认缺少按钮时失败，完成后 53 项前端全量测试与生产构建通过。独立只读审查未发现阻断问题。浏览器已核对按钮及限制提示。后端使用本地 HTTP 模拟服务验证路径、Bearer 鉴权、去重、无保存副作用、指定模型、最小对话及错误响应；真实供应商接口尚未调用。
