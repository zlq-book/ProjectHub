- 保留五列项目库，名称下展示真实 Git 摘要；时间列明确为“资料更新”。开发进度概览支持名称与状态筛选、读取数量和任务数量。

- 活跃度使用当前 HEAD 可达本地历史、全部作者、提交者 UTC 时间，前端按本地自然周期归桶；明确完整性与浅克隆范围。
- 独立 Git 摘要发送预览、完整请求 64 KiB 上限、敏感文件排除、仓库／内容／配置复核、单次令牌及取消。仅编辑后保存日志，不自动修改任务。
- SQLite v2 四类开发数据、日志／任务 CRUD、完成时间、revision 冲突保护、真实提交关联、移除归档及手动重绑；v1/v2 备份校验重建，恢复代次使旧保存失效。
- 助手新增固定 Git 状态／历史／活跃度／摘要引导工具，每轮最多 20 个项目；不使用资料更新时间替代代码开发时间。

## 独立审查与修复

Git、前端和整体数据／AI 路径分别经过独立审查。已修复：clean/process 过滤器可能执行外部程序、浅边界误当根提交、普通文本被二进制字面量误判、切页 busy 残留、未跟踪范围污染、重复摘要草稿丢失、清空正文退出编辑、慢模型无取消、长趋势裁切、导入前旧写请求污染恢复结果、无 HEAD 的状态回答遗漏、预览令牌泄漏。

## 实际限制

没有执行真实供应商请求、原生桌面 GUI 交互、安装器运行或干净机器安装。浏览器布局和模拟 HTTP 不代替上述验证。

部分克隆目前保守停止读取，不自动 fetch。仅当实际文件属性使用外部 clean/process 过滤器时拒绝工作区读取，避免禁用过滤器后误判 LFS 文件；历史仍可查看。子模块仅展示提交指针，其内部工作区未扫描且明确标为不完整，可作为独立项目录入。取消模型请求会忽略结果，已经发送的资料不能撤回。
