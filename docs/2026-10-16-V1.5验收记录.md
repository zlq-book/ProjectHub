# ProjectHub V1.5 AI 智能周报验收记录

日期：2026-10-16。源码版本：1.5.0。用户已授权按设计实施；本记录区分源码功能、自动化证据及未执行的原生验证。

## 实现范围

- 简洁 Windows 界面保留七项主导航，新增“AI 智能周报”，原发现项目与标签管理移入项目区工具栏，原 API 配置保留。
- 准备／编辑两个视图和历史列表；本周默认周一到周五，支持自定义日期。跨项目复用本人姓名／邮箱，可读取并人工确认作者候选。
- 当前 HEAD 可达历史，提交者时间归属日期，作者身份精确匹配；日志按业务日期独立筛选。同仓库同提交去重，保留多个项目关联。
- 默认提交说明、文件名及日志；Diff 主动逐文件选择。敏感文件、重命名敏感旧路径及二进制正文排除，发送预览对应实际 HTTP payload。
- 困难、计划、感悟仅润色人工要点；全部候选成果人工编辑，最多选 4 条。正式表格困难最多 3 条、计划最多 4 条、感悟一段。
- 草稿、乐观锁、历史版本与明确采用；重新生成先保存旧稿，新版不会自动采用。保存生成结果期间禁用取消和关闭，晚到回调检查请求代次。
- 来源保存项目、分支、HEAD、作者、两种提交时间、日志日期、日志关联提交、模型、选择的 Diff 路径及排除警告；不保存密钥和原始 Diff。
- SQLite v3 自动迁移，周报独立存储且不依赖实时项目外键；备份导入支持 v1／v2／v3。旧备份不含的周报恢复为空，导入前仍完整自动备份现库。
- Excel 固定模板保留栏目、合并、样式和序号，按文本写入、防止公式解释；长文本增加行高，超过固定表格可显示容量明确提示精简，不丢内容。Markdown 使用相同已保存版本，均不再次调用 AI。

## 技术路径调整

已使用工作区电子表格运行时从参考第四周文件生成清空内容的内置模板，独立读取确认没有原填报人及历史正文残留。生产打包使用模板中提取的固定 OOXML 资源，按 XML 元素定位单元格，使用限定用途的标准 ZIP Stored 打包函数输出 XLSX。

原计划的 ZIP crate 在当前 registry／网络环境无法解析，因此未引入新 Cargo 依赖，也未提高声明的 Rust 最低版本。该函数只输出可信的内置资源，具有长度检查、CRC32、中央目录和结束记录；不处理用户输入 ZIP 或通用解压。Python zipfile 的 CRC 校验、openpyxl 独立打开及电子表格渲染均已验证此输出。工作表通过内置资源嵌入二进制，生产运行不依赖 Python、参考文件路径或 Excel 安装。
