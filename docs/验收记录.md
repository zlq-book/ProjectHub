## 本地层代码覆盖

- Rust 提供目录规范化、可读性、重复路径校验、根目录有限字节识别、SQLite CRUD、设置、备份与事务导入命令。
- SQLite UNIQUE 保证并发去重；导入重建自身 schema，重算路径 key，拒绝重复 ID/路径、无效时间和设置。
- 应用内数据库操作串行化，导入对数据库加写锁；后续优化已将文件选择器移到锁外，慢磁盘读取仍可能让后续本地命令排队，但不会在 React 线程同步读取文件。
- 程序启动使用独立参数和 current_dir，不拼接 Shell 命令；终端启动不带 `-Command`。
- “移除项目”只执行 SQLite DELETE，项目目录没有删除、移动或写入调用。

代码存在不等于桌面运行已通过。补齐工具链后须实际执行 Cargo 测试，并验收真实目录、符号链接/联接点、断开的磁盘、各 IDE 启动参数、SQLite 重启持久化、备份往返与安装程序。
