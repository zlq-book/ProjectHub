# v0.2 项目整理版：迭代与验收

日期：2026-10-13。版本号：npm、Cargo 与 Tauri 均为 `0.2.0`，UI 标记 `v0.2`。数据库结构和 `user_version=1` 保持兼容。

## 新功能

- **发现项目**：多根目录、扫描深度、用户取消、有限数量/时间的只读扫描；跳过依赖/构建目录与目录链接。
- **预览导入**：候选名称、路径与技术栈，搜索筛选、显式勾选、统一分类，已存在的项目不能勾选。导入时再次校验，跳过重复/不可用路径并报告，数据库错误回滚全部新记录。
- **批量整理**：全选当前结果、收藏、取消收藏、调整分类、移除索引；操作数量、跨筛选保留提示、全部项目清单确认。
- **数据保护**：SQLite 批量更新/移除使用事务，不修改项目文件；浏览器示例持久化一次，失败保持原数据。

## 限额与取消语义

每次扫描接受 1–20 个根目录，扫描根目录及最多 1–4 层子目录；不扫描依赖和构建目录内部。上限为 5000 个访问目录、20000 个目录项、500 个候选。

15 秒为协作式遍历预算，在根目录处理、目录/条目循环、识别前后检查。同步文件系统调用无法被中途终止，所以单次调用耗时长时会等待其结束；随后检查取消/预算并停止。取消请求后前端拒绝迟到的成功结果；关闭对话框也发出取消请求。扫描从不写项目库。

1. 补齐 Rust、MSVC/SDK，然后执行 `cargo test --manifest-path src-tauri/Cargo.toml`。
2. 准备独立测试根目录，包含 Java/Node/Python/.NET 项目和 node_modules/target/dist 子目录，验证多根去重、深度与排除规则。
3. 加入 Windows 联接点/符号链接，验证不进入链接目录；测试不可访问目录的提示。
4. 扫描时取消、识别结束时取消、关闭弹窗后重新扫描，验证不会自动落库或接受已取消结果。
5. 导入重复/消失路径，验证跳过结果；在测试数据库制造写入失败，验证事务回滚。
6. 批量删除索引后检查本地文件仍存在；重启桌面软件验证资料保存。
7. `npm.cmd run package:windows` 构建 NSIS 安装包并实际安装测试。
