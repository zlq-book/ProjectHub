# 极简 Windows 开发工具界面

设计依据：用户 2026-10-14 提供的参考图及六项调整。发布版本号仍为 0.3.0，本次将界面按 V1.0 主要设计方向实现。

- 白灰中性界面，蓝色强调主要操作、选择与导航；技术栈统一浅灰，深色主题使用对应中性灰。
- 新项目库默认列表，按名称、简介、技术栈、路径、最近更新时间五列显示；46 px 行高，长文本省略并可悬停查看。窄窗口可横向滚动，不隐藏列。
- 保留卡片及其持久化偏好；现有已保存的卡片偏好不强制覆盖。
- 侧栏仅保留常用功能与分类，移除底部统计、进度条、重复添加按钮及装饰文案。
- 分类页签、搜索、状态筛选、排序、标签管理、发现、批量操作均保留。
- 单击选择并展示详情，关闭详情保留选中并释放列表宽度。卡片鼠标单击即时高亮，延迟 500 ms 展开面板，双击取消延迟并使用默认工具；键盘选择即时展开。
- 详情展示 Git 仓库、当前分支、路径可用状态、路径、分类和时间；主按钮直接打开 IDEA，终端和目录作为次操作，其他操作折叠保留。
- Git 使用选中项目 ID 查询实际路径，固定参数执行只读 Git 命令，无 Shell，不联网。每个 Git 命令 3 秒预算，错误与缺失状态明确提示；远程 URL 凭据与查询参数不展示。异步返回不会覆盖另一个项目。

## 验证

- `npm.cmd test`：7 个测试文件、45 项通过，覆盖列表／卡片、视图保存、键盘选择、详情收起、默认工具双击、批量模式、Git 显示及过期响应隔离，以及现有标签／发现／录入流程。
- `cargo test --offline --manifest-path src-tauri/Cargo.toml`：24 项通过，覆盖真实临时 Git 仓库的分支、origin、无 origin、普通目录、目录缺失和远程凭据脱敏，以及既有 SQLite、扫描和路径逻辑。
- `npm.cmd run build`：TypeScript 与 Vite 生产构建通过，输出至 `dist/`。
- 浏览器检查了 1536、1440、1100、760、375 px 窗口。1536 px 下关闭详情后内容区宽度从 960 px 增至 1320 px，保留当前选择；375 px 下页面自身不产生横向溢出，项目表格内部滚动。深色标签实际背景为 rgb(51,53,59)，文字为 rgb(192,195,203)。
- 浏览器双击卡片确认进入打开接口并显示桌面版限制；浏览器无法证明 IDEA 实际启动。未执行真实桌面启动验收，未重新生成安装包，现有安装包不包含本次调整。
