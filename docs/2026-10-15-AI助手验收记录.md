实施日期：2026-10-15，最终复核日期：2026-10-16。对应已确认的 [首版设计](./superpowers/specs/2026-10-15-projecthub-ai-assistant-design.md)。

## 实现范围

- 右上角 AI 助手入口；详情与助手共享右栏。无选中项目、空库均可打开，收起或切换保留本次会话及草稿。
- 自然语言检索真实项目元数据，返回卡片、分类、技术栈与可核对证据；可查看详情或主动将结果应用到项目列表。
- 白名单 README／依赖生成单项目简介，建议可编辑，单独确认后只更新简介与资料时间。
- 分类建议逐项勾选、修改目标分类并原子保存；已有证据的建议可先确认，资料不足行等待补充。
- 独立的资料读取确认，初次发送 contextIds 为空；最多 3 个项目，并且只能读取本轮范围内的已登记项目。
- 严格枚举意图与参数、真实 ID／证据校验、请求预算、取消晚到防护、10 分钟建议有效期、快照冲突检测、相同修改幂等重放。
- 浏览器不调用模型、不保存密钥、不读取真实本地项目。模型配置保持一套，不新增供应商设置或依赖。

## 关键回归与修复

1. 首次测试确认右上入口缺失导致新增 App 测试失败，完成接入后通过。
2. 新会话未重新展示发送范围、离线目录被默认选中，两项组件测试先失败，修复后通过。
3. 独立前端审查发现：助手保存期间能够打开旧全字段编辑表单。新增 App 回归确认失败，增加全局提交状态、弹窗入口锁与已有弹窗检查，修复后通过。
4. 搜索卡片补充分类展示；零命中仍可主动选择本轮项目补充资料，不能让 AI 自动读取。
5. 混合分类测试确认单个 needsContext 候选曾阻塞全部建议；后端改为保留可写建议，未完成判断的行不进入可保存快照，前端禁止提交没有分类建议的行。
6. 元数据压缩为极端旧备份 ID 增加硬停止，完整模型请求 JSON 按 64 KiB 上限检查并明确标记截断。
7. 测试框架模拟服务器的取消等待改为通道同步与有界 accept，避免任务在下个请求之前取消而测试无限等待。
8. 最终审查新增否定时间与 README 重复读取回归，实际复现 18 项中 2 项失败。修复后，“近一个月没有打开”按固定参考时间的 30 天上界过滤，结果明确说明包含从未打开记录；“近一个月没有修改资料”只使用资料更新时间。
9. 复审补充“排除近一个月打开”的外围否定用例，先验证旧子串规则会反转结果。时间修正现仅识别完整的简单表达，复杂／多条件请求保留模型已解析并通过校验的边界；不会把其他条件中的“没有”或外围“排除”当作正向打开条件。
10. README 在普通文件检查之后按规范路径去重，再读取及扣预算；32 KiB README 不再在 Windows 被两种大小写读两次，仍能读取 `pom.xml`。额外保留大小写敏感文件系统下两个独立 README 的用例；该分支仅在实际文件系统支持时执行，不代表已在 Linux 实机验证。
