# v0.3 标签整理版

依据原设计的标签管理需求继续迭代，保留三栏界面和已有数据结构。

## 范围与约定

- 自定义标签和技术栈分开展示，分别搜索和统计项目数量。技术栈只提供筛选，编辑仍在项目资料表单。
- 自定义标签支持重命名与移除。标签名称区分大小写；输入目标名去首尾 Unicode White_Space 与 BOM，非空且最多 80 个 Unicode 字符。
- 重命名到已有标签时合并，保持首次出现顺序并去重；只更改 `tags`，不改 `techStack`。
- 点击操作后冻结受影响项目清单，确认框列出所有名称和路径。最多 500 条；超出提示分批使用项目资料编辑。
- 服务接收明确 ID 清单、源标签和可空目标标签。ID 缺失、源标签消失或输入非法时整批失败，不部分更新；移除标签不会移除项目。
- 桌面采用 SQLite 单事务，浏览器采用一次持久化后替换内存。失败保留清单便于重试。
- 更新成功合并返回项目；自定义及混合来源的当前筛选随标签重命名/移除同步，明确的技术栈筛选保持原值。
- 项目资料的标签/技术栈文本未修改时保留原数组，避免编辑其他字段时拆分含逗号的标签；主动修改仍按既有逗号分隔规则解析。
- 不新增依赖，不改变数据库 schema，不执行项目脚本。
